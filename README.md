# Button Customizer + Pass/Fail

Merged and maintained as one add-on. It combines the core Pass/Fail behavior with KING-derived reviewer button styling and adds 2/3/4-button modes, independent light/dark background and text colors, pixel-based sizing, bottom-bar sizing, a Tools configuration window, side-by-side configuration documentation, a live preview, and compatibility work for Anki 26.09.4+fsrs7 (7259f40e).

Disable the original PassFail2 and KING add-ons before using this merged add-on. The manifest declares conflicts with their package IDs so they cannot be enabled alongside it.

Source: https://github.com/AgusssChh/Button-Customizer-Pass-Fail
